# Backlog

Ideas and notes for future skills and changes. Add to it freely; move an item to a PR when work starts.

## Skill ideas

- **mkl-ux-copy (UI copywriting).** How to write button labels, empty states, errors, confirmations and other interface text. Kept separate from mkl-typography: typography is how words are set, copywriting is which words. A separate skill also triggers on its own when an agent is writing UI text. mkl-typography covers only the typographic side of copy (case, quotes, dashes, numbers, units). Check overlap with existing UX-writing skills during grilling.

## Process

- New skills start with `/grilling`, then the `deep-research` skill, then fact-check, compare, draft, and a PR. See the project instructions.
